Built so a mistake can't cost you your files.

Every item goes through the same checks right before it's cleaned, not just when it was found.

Trash first

Anything you might want back goes to the Trash. Caches that rebuild themselves are the only things removed outright, and you can choose the Trash for those too.

Nothing in use

If an app or tool is running or holds a lock on a folder, Roomy waits. Quit it and scan again.

Your work stays

A project is only suggested when every file is committed and every commit is pushed. Build folders of projects you touched this week are left alone.

Your folders are off limits

Documents, Desktop, Pictures, Movies and Music are never suggested, except big installers and disk images you can review yourself.

Honest sizes

Roomy counts the space a folder really frees on APFS, so shared clone blocks don't make the number look bigger than it is.

You confirm everything

You see what will go and how, then confirm. Nothing runs on its own, and every clean is logged.

Also a command line tool.

The engine is a fast Rust program, and everything the app does works from Terminal too.

It shows honest sizes, checks safety the same way, and prints JSON for scripts.

Terminal
$ roomy scan              # what can be freed, explained
$ roomy map               # where the space goes
$ roomy clean --safe      # clean what's safe (asks first)
$ roomy known ~/.cache/uv # what is this folder?
$ roomy uninstall /Applications/Slack.app
$ roomy leftovers         # files of apps already gone
$ roomy packages          # Homebrew, npm, uv and pipx

Teach Roomy your Mac.

Every Mac has different apps. Give this prompt to Claude Code, Codex or any agent that can run commands. It finds the folders Roomy doesn't know yet and sends them back, so every Mac with the same apps gets the answer.

Prompt for your agent
You're helping improve Roomy, a Mac cleaner whose code is on GitHub (https://github.com/jurek-zsl/Roomy).
Roomy ships a list of known folders in rules/known.toml. Find big folders on this Mac
that the list doesn't know yet, and add them. Don't delete or change anything on this Mac.

1. Clone the repo and build the engine:
   git clone https://github.com/jurek-zsl/Roomy && cd Roomy && cargo build --release
2. Map the disk: ./target/release/roomy map --json > /tmp/roomy-map.json
   (Give your terminal Full Disk Access first, or many folders stay hidden.)
3. Take every folder of 100 MB or more from the map and run
   ./target/release/roomy known <paths...>
   Keep the folders that print "not on the list", and those only matched by a general
   entry ("An app's data", "An app's cache", "A tool's cache", "An app's sandbox").
4. For each one, find out what it really is: run ./target/release/roomy inspect <path>,
   look at the app or tool it belongs to, and check that tool's documentation or website.
   Don't guess. Never open, read or copy the contents of the person's own files.
5. Add an entry to rules/known.toml in the right section, using the format at the top
   of that file: path (~ for home, never a username), name, owner, what (one or two plain
   sentences ending with a period), kind, regrows, and how if the tool has its own clean
   command. Be honest about kind: anything a person would miss (chats, saves, projects,
   settings) is appData or userFiles, never cache.
6. Run cargo test, and check that ./target/release/roomy known <path> now names each folder.
7. Open a pull request listing each folder you added, its typical size, and the source
   you checked. Leave out usernames, personal file names and anything private.

Questions.

Does Roomy send my files anywhere?

No. Scanning, Quick Scan and cleaning all happen on your Mac. Only if you start an AI Scan or ask an AI about a folder does Roomy send folder names and sizes, never file contents, to the AI you chose, after showing you exactly what goes.

Do I need an AI subscription?

No. Roomy's own rules and its list of known folders work offline. AI Scan is optional and uses the Claude Code, Codex or Gemini command you already have.

Why does it ask for Full Disk Access?

macOS hides other apps' containers, Mail and system data from apps by default. With access, Roomy can map the whole disk and find leftovers. It still only cleans what you confirm.

Can I get something back?

Yes. Anything that isn't a cache that rebuilds itself goes to the Trash, so you can put it back until you empty the Trash.

Why isn't it on the Mac App Store?

App Store apps live in a sandbox that hides exactly the caches Roomy cleans. Roomy is signed with a Developer ID and notarized by Apple instead.

Which Macs does it run on?

macOS 14 Sonoma or later, on Apple silicon and Intel Macs.

What are Time Machine local snapshots?

When your backup disk isn't connected, Time Machine keeps hourly snapshots on your Mac. They can hold many gigabytes, and macOS doesn't show their size. Roomy lists them in System Data and can delete them; your backups on the backup disk stay.
